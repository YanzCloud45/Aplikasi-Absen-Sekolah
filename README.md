# 📱 Absen Sekolah - Android App

Aplikasi Android WebView untuk sistem absensi sekolah digital.

## 🌐 Website Target
**https://yanzhost.wuaze.com**

## ✨ Fitur
- 🔐 Login session tetap tersimpan (Cookie Manager)
- 🎨 Splash screen dengan animasi
- 📶 Deteksi offline + halaman error
- 🔄 Swipe to refresh
- 📊 Progress bar loading
- ↩️ Back button navigation
- 📁 File upload support
- 📱 Min SDK 21 (Android 5.0 Lollipop+)
- 📦 APK size < 5MB

## 🔨 Build

### Android Studio
1. Open project di Android Studio
2. Sync Gradle
3. Build → Build APK(s)

### Command Line
```bash
./gradlew assembleDebug
```

### GitHub Actions
Push ke GitHub dan APK otomatis di-build.
